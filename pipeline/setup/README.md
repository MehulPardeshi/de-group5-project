# Shared setup

**Owner:** Mehul · **Issue:** [#13](https://github.com/MehulPardeshi/de-group5-project/issues/13)

SQL and notes for the shared databases go here. This includes creating the `raw` and `clean` schemas and the MongoDB or S3 setup.

## How to connect
1. Get the logins from Mehul in a private WhatsApp message. They are never posted in the group or on GitHub.
2. Copy `.env.example` to `.env` in the repo root and fill in the values. Git ignores `.env`.
3. Install the Python packages: `pip install -r requirements.txt`
