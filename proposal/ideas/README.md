# Topic ideas

Everyone adds their ideas here with a pull request. No git install is needed.

1. Open this folder on GitHub, then choose **Add file → Create new file**.
2. Name the file after yourself, like `joshua.md`.
3. Copy the template below and fill it in. Add a second copy if you have two ideas.
4. Click **Commit changes**, choose **Create a new branch**, then **Propose changes**.
5. Write `Part of #4` in the description and click **Create pull request**.

## Template

```markdown
## Idea: <short name>

- **Context:** business, environment, sports, public services...
- **Real-world problem:**
- **Who would benefit:**
- **Datasets I know of (with links):**
- **Why I care about it:**
```
