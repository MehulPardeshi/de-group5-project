## What goes in your folder

- The query or script that answers the question, reading only from the `serving` tables ([#23](https://github.com/MehulPardeshi/de-group5-project/issues/23))
- 1–2 charts (PNG is fine) that answer the question. They don't need to be fancy.
- A short `README.md`: the answer in a few sentences, and its limitations

The agreed definitions (period, bad weather, severe weather, usual rates, recovery) are in [#76](https://github.com/MehulPardeshi/de-group5-project/issues/76). Never commit data files or query results exported as CSV.
